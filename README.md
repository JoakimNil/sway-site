# Sway site

This folder is the public privacy-policy page for the Sway Android app, kept here because the app repo is private.
To publish: copy the contents into a small public repo (e.g. `sway-site`), enable GitHub Pages on it, and use the resulting URL in Play Console and the app.
Before publishing, replace `CONTACT_EMAIL_PLACEHOLDER` in `index.html` with the real support email (grep for it).
